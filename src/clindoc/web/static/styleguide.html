Page skeleton

Every page uses this shell. mountShell() fills the header and footer placeholders, adds the skip link, marks the nav item matching body[data-page] (home, workbench, playground, explorer, results, model, docs), and wires theme toggle, tabs, reveal, copy buttons and dialog triggers.

Buttons

44px minimum target. .btn--cta (accent) is for the single main action of a page; .btn--primary for primary actions in tools. Icon-only buttons need aria-label. While a request runs set aria-busy="true" and disabled.

Form controls

Every control has a visible <label>; help and errors are linked with aria-describedby; invalid fields get aria-invalid="true". Chips and segmented controls are native checkboxes/radios, so arrow keys and Space work.

Tabs and accordion

Tabs: initTabs() runs inside mountShell(). Add data-tabs-param="tab" to sync the selected tab with the URL. Listen for the bubbling tabchange event. Accordion is native <details>.

Dialog and drawer

Native <dialog>: the page behind is inert (focus stays inside), Esc closes, focus returns to the opener. Open with data-dialog-open="#id" or openDialog(el); close with data-dialog-close, backdrop click or closeDialog(el).

Loading, empty and error states

Show skeletons first, then content, or renderError(el, err, retry) / renderEmpty(el, opts). On refetch keep the previous render and add .is-loading-frame instead of flashing skeletons.

Toasts and tooltips

toast(message, { kind, title, timeout }) announces politely (danger uses role=alert). Tooltips show on hover and focus and hide on Esc; never put essential content only in a tooltip.
